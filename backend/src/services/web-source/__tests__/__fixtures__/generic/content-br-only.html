第7章 夜渡

廣告位

    她低頭看著掌心的紋路，忽然覺得那條線比昨日更長了些。晨霧尚未散去，山道上只剩下腳步聲與遠處的水流聲。守夜的人在牆邊打了個哈欠，隨即又把腰背挺直。
    院子裡的老樹落下幾片葉子，無聲地鋪在青磚上。風從谷口吹進來，帶著一股潮濕的草木氣息。她低頭看著掌心的紋路，忽然覺得那條線比昨日更長了些。
    他把手裡的燈籠換到左手，順著石階往上走了幾步。遠處傳來三聲鐘響，像是在提醒眾人時辰已到。院子裡的老樹落下幾片葉子，無聲地鋪在青磚上。
    守夜的人在牆邊打了個哈欠，隨即又把腰背挺直。桌上的茶已經涼透，杯壁凝出一層薄薄的水珠。他把手裡的燈籠換到左手，順著石階往上走了幾步。
