　　第12章 石橋

　　他把手裡的燈籠換到左手，順著石階往上走了幾步。遠處傳來三聲鐘響，像是在提醒眾人時辰已到。院子裡的老樹落下幾片葉子，無聲地鋪在青磚上。

　　守夜的人在牆邊打了個哈欠，隨即又把腰背挺直。桌上的茶已經涼透，杯壁凝出一層薄薄的水珠。他把手裡的燈籠換到左手，順著石階往上走了幾步。
