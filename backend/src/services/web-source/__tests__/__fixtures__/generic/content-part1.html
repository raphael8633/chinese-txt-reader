第15章 分頁（1/3）

　　院子裡的老樹落下幾片葉子，無聲地鋪在青磚上。風從谷口吹進來，帶著一股潮濕的草木氣息。她低頭看著掌心的紋路，忽然覺得那條線比昨日更長了些。

　　他把手裡的燈籠換到左手，順著石階往上走了幾步。遠處傳來三聲鐘響，像是在提醒眾人時辰已到。院子裡的老樹落下幾片葉子，無聲地鋪在青磚上。
